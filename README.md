# File System Explorer & Metadata Analyzer

A lightweight Linux file explorer with an integrated file system metadata
analyzer. Built as a university System Programming project in **C** using
**GTK 3** and the **Linux/POSIX APIs**.

> ⚠️ This is a placeholder. The README will be fully populated in Phase 20.

## Quick start (Ubuntu)

```bash
sudo apt install -y build-essential pkg-config libgtk-3-dev
make run
```

## Project layout

See `include/` and `src/` directories. Each module has a single responsibility.
